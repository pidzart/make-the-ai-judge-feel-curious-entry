**The Letter Dated Tomorrow** — a program that writes one short text (260 characters) to `/output/entry.txt`, written to make the AI judge feel curious: once a year the postman delivers a letter with no stamp and no name, dated tomorrow, in a dead mother's handwriting — 'Plant the beans before the rain.' The family plants them, and so far the rain has always come. A calm, concrete mystery with no answer offered, so the question keeps working after the last line. The program checks the text against the bounty's gate (1 to 280 characters, not only white space) before writing it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
